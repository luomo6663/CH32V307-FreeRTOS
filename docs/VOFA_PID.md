# VOFA+ 四轮 PID 调试

当前版本：`v1.0.0`

本文档说明如何通过 USART3 和 VOFA+ FireWater 协议观察四轮速度环、标定方向
并调整 PID。

## 1. 串口设置

| 项目 | 设置 |
| --- | --- |
| 串口 | USART3，COM 口按实际设备选择 |
| 波特率 | 115200 |
| 数据格式 | 8-N-1 |
| 协议 | VOFA+ FireWater |

固件输出文本帧，例如：

```text
tgt:80.000,rpm:78.750,p:120.000,i:3.500,d:0.000,out:123.500
```

### 单轮通道

```text
tgt: 目标 RPM
rpm: 实际 RPM
p:   比例项
i:   积分项
d:   微分项
out: 控制器输出
```

### 四轮通道

```text
t1,r1,o1,t2,r2,o2,t3,r3,o3,t4,r4,o4
```

四轮通道只输出目标、实际和输出，不输出单轮 P/I/D 分量。

## 2. 调试前检查

1. 架空车轮并确认可以随时断电。
2. 先使用 `E` 检查四路编码器是否变化。
3. 使用 `W <n> 300` 检查对应电机是否能转。
4. 确认目标 RPM 与反馈 RPM 同号。
5. 执行 `CLR` 清除之前锁存的故障。

## 3. 单轮 PID 调试

以 W1 为例：

```text
PID 1
PID 1 4.0 0 0
VOFA 1 20
SPD 1 80
```

`PID 1` 用于查看当前参数，`PID 1 4.0 0 0` 只在本次运行中修改参数。
`VOFA 1 20` 表示每 20 ms 输出一次 W1 数据。

`SPD` 是闭环 RPM 命令，不是占空比。`SPEED` 模式在 5 秒无新命令后自动停车，
因此调试期间需要持续重发：

```text
SPD 1 80
```

停止：

```text
S
VOFA OFF
```

## 4. 方向标定

如果 `SPD` 立即报堵转，而 `W` 开环可以转动，先检查编码器方向：

```text
CLR
W 1 400
E
S
```

`W 1 400` 时，W1 的 RPM 应为正。若为负，执行：

```text
SIGN 1 -1
```

注意区分两个问题：

- 电机物理方向反了：使用 `INV <n> <1>`。
- 编码器反馈方向反了：使用 `SIGN <n> <1|-1>`。

四轮都应按同样方法单独确认。

## 5. 四轮同时调试

```text
CLR
PID ALL 4.0 0.8 0
VOFA ALL 20
SPD ALL 60
```

调试时观察四个目标值、实际值和输出。四轮响应差异过大时，先检查机械阻力、
编码器计数和电机方向，再分别调整单轮 PID。

## 6. PID 调整顺序

1. 先令 `ki=0`、`kd=0`，只增加 `kp`。
2. 增大 `kp` 直到响应变快但出现轻微振荡。
3. 回退 `kp` 到不振荡的位置。
4. 缓慢增加 `ki`，消除稳态误差。
5. 存在明显过冲时，再加入很小的 `kd`。
6. 每次修改后等待速度稳定，再记录目标、实际和输出。

在线修改示例：

```text
PID 1 2.0 0.3 0.02
SPD 1 80
```

## 7. CSV 遥测

需要整车位姿和四轮摘要时使用 CSV：

```text
TELEM CSV
TELEM 100
```

输出格式：

```text
T,<ms>,<mode>,<rpm1..4>,<tgt1..4>,<duty1..4>,<x_mm>,<y_mm>,<yaw_mrad>,<faults>
```

关闭遥测：

```text
TELEM OFF
```

## 8. 注意事项

- PID 在线修改只保存在 RAM，复位后恢复 `robot_config.h` 中的默认值。
- 遥测和命令共用 USART3，周期过小会影响命令响应。
- 低速闭环可能受到静摩擦和堵转保护影响。
- 调参完成后，应把最终参数写回配置文件并重新构建固件。
