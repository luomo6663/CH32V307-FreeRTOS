# 底盘、硬件和命令说明

当前版本：`v1.0.0`

本文档说明四轮麦轮底盘、舵机、转台的硬件连接、控制台命令、标定方法和安全
限制。模块分层和任务模型见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 1. 硬件概览

| 项目 | 参数 |
| --- | --- |
| 主控 | CH32V307VCT6，系统时钟 96 MHz |
| RTOS | FreeRTOS 202112.00，RISC-V PFIC port |
| 电机驱动 | TMI8140 x4，支持双 PWM 或 PWM + DIR |
| 电机 | JGB37-520，11 线编码器，32:1 减速比 |
| 底盘 PWM | 24 kHz，TIM2 和 TIM4 |
| 控制台 | USART3，PB10 TX / PB11 RX，115200-8-N-1 |
| 舵机 | PB5，TIM3_CH2，50 Hz |
| 步进转台 | PA0 STEP/TIM5_CH1，PA1 DIR |

### 电机、编码器和车轮映射

| 轮号 | 位置 | 电机 IN1/IN2 | 编码器 A/B | 编码器定时器 |
| --- | --- | --- | --- | --- |
| W1 | 右后 | PA2 / PA3 | PC6 / PC7 | TIM8_CH1/CH2 |
| W2 | 右前 | PA15 / PB3 | PD1 / PD3 | TIM10_CH1/CH2，全重映射 |
| W3 | 左前 | PD12 / PD13 | PA8 / PA9 | TIM1_CH1/CH2 |
| W4 | 左后 | PD14 / PD15 | PD9 / PD11 | TIM9_CH1/CH2，全重映射 |

四路编码器都使用正交四倍频。单圈计数为：

```text
11 PPR * 32 减速比 * 4 倍频 = 1408 counts/rev
```

### CH32V307 复用说明

- 调试口只有两线 SDI：`SWDIO=PA13`、`SWCLK=PA14`。
- `PA15` 使用 `TIM2_CH1_1`，`PB3` 使用 `TIM2_CH2_1`。
- TIM2 使用部分重映射 1，TIM4、TIM9 和 TIM10 使用完全重映射。
- `PA15/PB3` 不需要释放 JTAG 引脚。

## 2. 上电状态

- 电机保持滑行，不自动转动。
- 舵机输出 `1500 us` 中位。
- 步进转台保持停止，STEP 为低电平。
- 控制台等待命令，默认不开启遥测。

运行期的 PID、方向、编码器符号和转台 PPR 只保存在 RAM，复位后恢复
`User/config/robot_config.h` 中的值。

## 3. 指令表

命令不区分大小写，参数使用空格分隔。`vx` 正方向为前，`vy` 正方向为左，
`wz` 正方向为左转。

### 3.1 底盘运动

| 动作 | 指令 | 说明 |
| --- | --- | --- |
| 前进 | `V 150 0 0` | 向前 150 mm/s |
| 后退 | `V -150 0 0` | 向后 150 mm/s |
| 左移 | `V 0 150 0` | 向左横移 150 mm/s |
| 右移 | `V 0 -150 0` | 向右横移 150 mm/s |
| 原地左转 | `V 0 0 1.0` | 左转 1.0 rad/s |
| 原地右转 | `V 0 0 -1.0` | 右转 1.0 rad/s |
| 左前斜行 | `V 100 100 0` | 向左前方运动 |
| 右前斜行 | `V 100 -100 0` | 向右前方运动 |
| 左后斜行 | `V -100 100 0` | 向左后方运动 |
| 右后斜行 | `V -100 -100 0` | 向右后方运动 |
| 边走边转 | `V 100 0 0.5` | 前进同时左转 |
| 停车 | `S` / `STOP` / `X` | 目标清零并滑行 |
| 刹车 | `B` | 四轮主动刹车 |
| 状态 | `P` / `STATUS` | 查看模式、故障、RPM 和输出 |
| 帮助 | `H` / `?` | 打印控制台帮助 |

`V` 指令必须在 `ROBOT_COMMAND_TIMEOUT_MS` 内重复发送，否则底盘自动停车。

### 3.2 标定与维护

| 指令 | 说明 |
| --- | --- |
| `W <n> <duty>` | 单轮开环，`n=1..4`，占空比 `-1000..1000` |
| `M <d1> <d2> <d3> <d4>` | 四轮分别开环控制 |
| `SPD <n\|ALL> <rpm>` | 单轮或四轮闭环速度标定 |
| `PID <n\|ALL> [kp ki kd]` | 查询或设置速度环参数 |
| `OL <n> <gain>` | 设置缺反馈轮的开环占空比/转速比 |
| `RAMP <n>` | 每个控制周期的占空比变化上限，`0` 为关闭 |
| `INV <n> <0\|1>` | 设置电机方向取反 |
| `MODE <0\|1>` | `0` 为双 PWM，`1` 为 PWM + DIR |
| `E` | 查看编码器计数、增量、RPM 和电平变化 |
| `E R` | 清零编码器计数、诊断标志和里程计 |
| `SIGN <n> <1\|-1>` | 设置编码器反馈符号 |
| `POSE` / `POSE R` | 查看或清零里程计位姿 |
| `CLR` | 清除锁存故障 |
| `CFG` | 查看时钟、PWM、周期和限幅 |
| `TELEM <on\|off\|ms\|csv>` | 控制 CSV 遥测 |
| `VOFA <n\|ALL\|OFF> [ms]` | 控制 VOFA+ FireWater 输出 |

### 3.3 舵机和转台

| 指令 | 说明 |
| --- | --- |
| `SERVO` | 查看脉宽、扫描状态和定时器寄存器 |
| `SERVO <500..2500>` | 设置脉宽，`1500` 为中位 |
| `SERVO SWEEP [ms]` | 在 1000–2000 us 间手动扫描 |
| `SERVO HOLD` | 停止扫描并保持当前脉宽 |
| `TURN` | 查看位置、目标、方向和脉冲速率 |
| `TURN <deg> [rpm]` | 相对移动指定角度 |
| `TURN RUN <CW\|CCW> [rpm]` | 连续旋转 |
| `TURN STOP` | 停止并拉低 STEP |
| `TURN ZERO` | 把当前位置设为零 |
| `TURN PPR <n>` | 设置每圈脉冲数 |
| `TURN PULSES <n> [hz]` | 按指定频率发送脉冲 |

## 4. 遥测格式

CSV 数据格式：

```text
T,<ms>,<mode>,<rpm1..4>,<tgt1..4>,<duty1..4>,<x_mm>,<y_mm>,<yaw_mrad>,<faults>
```

VOFA+ 单轮通道：

```text
tgt,rpm,p,i,d,out
```

VOFA+ 四轮通道：

```text
t1,r1,o1,t2,r2,o2,t3,r3,o3,t4,r4,o4
```

详细调参方法见 [VOFA_PID.md](VOFA_PID.md)。

## 5. 标定流程

1. 架空车轮，确认急停或断电手段可用。
2. 使用 `W <n> 300` 检查对应电机和编码器。
3. 使用 `E` 确认轮号、编码器方向和电平变化。
4. RPM 方向错误时使用 `SIGN <n> -1`。
5. 电机物理方向错误时使用 `INV <n> <1>`。
6. 使用 `SPD <n> 40` 进行低速闭环检查。
7. 四轮分别确认后，使用 `SPD ALL 40` 检查整体一致性。
8. 从低风险速度开始测试 `V`，确认前后左右和转向方向。

在线 PID 和标定值只写入 RAM。确认最终参数后，应写回
`User/config/robot_config.h` 并重新构建固件。

## 6. 安全和故障处理

- `DRIVE` 命令超时后停车并锁存 `COMM_TIMEOUT`。
- 车轮缺少反馈时拒绝进入 `DRIVE`。
- 堵转和反馈反接会锁存车轮故障。
- `DRIVE` 中任一车轮故障会停止整车。
- `SPEED` 中故障轮滑行，其他轮继续运行，便于台架标定。
- `S` / `STOP` / `X` 返回 `IDLE` 并让电机滑行。
- `B` 对四轮执行主动刹车。
- `CLR` 只清除锁存故障，不替代机械检查。

## 7. 实机验证结果

当前硬件已使用 COM8 完成以下验证：

| 测试 | 结果 |
| --- | --- |
| `M 250 250 250 250` | 四轮约 72–80 rpm |
| `SPD ALL 40` | 四轮均为 `closed`，实测约 34 rpm |
| `V 150 0 0` | 实测约 132 mm/s，四轮闭环正常 |
| `V 0 0 1.0` | 原地转向四轮闭环正常 |
| `SERVO 1400/1500/1600` | 脉宽和寄存器一致 |
| `SERVO SWEEP` / `HOLD` | 扫描和保持正常 |
| `TURN 10 1` / `TURN -10 1` | 实测 10.013 度，并能回到零点 |
| `TURN RUN CW 1` / `STOP` | 连续运行和停止正常 |

从静止直接执行 `V 0 0 0.5` 时，车轮可能在地面静摩擦阶段触发 0.5 秒堵转
保护。先用 `V 0 0 1.0` 起步后降到 `0.5 rad/s` 可以稳定运行。若需要改善
静止启动，应扩大 `ROBOT_PID_STALL_LIMIT` 并重新验证安全停机时间。

## 9. 已知限制

- 轮径和轮距未做长距离实测标定，里程计会有累积误差。
- 麦轮自转项使用 `(半轴距 + 半轮距)` 简化模型。
- 低速转向从静止启动可能触发堵转保护。
- 运行期参数不会自动保存到 Flash。
