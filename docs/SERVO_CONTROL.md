# 舵机控制

## 真实方向与硬件标记

实测确认：真实右臂 R 接硬件标记 L，PD2=1；真实左臂 L 接硬件标记 R，PD2=0。
命令 SIDE、状态 requested/control/routed 均表示真实机械臂，不表示 PCB 标记。
状态中的 hardware-label 单独显示板上分组。H 接口编号按所提供原理图标注，
排针实际位置及缺失接口仍需现场核实，不通过软件检测。

| 逻辑通道 | 功能 | 引脚 / 定时器 | 真实R（硬件L）原理图接口 | 真实L（硬件R）原理图接口 | R限位 |
| --- | --- | --- | --- | --- | --- |
| A | 底部 | PB4 / TIM3_CH1 | H5 | H21 | 750–1500 us |
| B | 中间 | PB5 / TIM3_CH2 | H6 | H3 | 850–1500 us |
| C | 爪子 | PB0 / TIM3_CH3 | H7 | H4 | 850–1500 us |

A/C 按最新实物反馈重新对调输出。左臂未标定，保留手动电气范围500–2500 us，不开放预设。
三针接口原理图编号为1=GND、2=VSER、3=PWM，插接方向须根据实物确认。

## 启动和PWM

上电默认真实R，A/B/C均1500 us，300 Hz，不自动扫描。
计数频率由实际APB1定时器时钟分频到1 MHz；96 MHz主频、APB1=48 MHz时，
TIM3=96 MHz、PSC=95、ARR=3332。PWM2低极性输出周期开始的高电平脉冲。
逻辑A/B/C写入CH1/CH2/CH3的比较预装载，下一次溢出生效，不依赖TIM3中断。
状态CCR按硬件CH1/CH2/CH3排列，即逻辑A/B/C。
切换前清零输出，非阻塞等待20 ms后改变PD2，恢复另一侧保存的输出。
未选中侧没有持续PWM，保存的软件脉宽不代表实际轴位置或保持力矩。

## 手动命令

USART3，115200波特率，每条换行，大小写不敏感。

| 命令 | 行为 |
| --- | --- |
| SERVO / SERVO MAP / SERVO LIMIT | 查看映射、限位、脉宽、运动与预设状态 |
| SERVO SIDE R / SERVO SIDE L | 选择真实侧别 |
| SERVO B 1200 | 当前侧B直接设脉宽，A/C/ALL同理 |
| SERVO 1200 | 兼容命令，控制当前侧B |
| SERVO MOVE A 875 1000 | A用1000 ms缓起缓停移到875 us |
| SERVO POSE 875 1500 1500 1000 | A/B/C同时用1000 ms到目标 |
| SERVO JOG A -10 500 | A相对当前软件目标减10 us，时间500 ms |
| SERVO CENTER [A/B/C/ALL] | 当前侧指定通道回配置中位，省略为ALL |
| SERVO HOLD | 丢弃待执行舵机命令，取消后续预设步骤，保持当前侧全部输出 |
| SERVO OFF | 丢弃待执行舵机命令，取消动作，关闭当前侧全部输出 |
| SERVO HELP | 查看命令 |

HOLD/OFF为整侧取消，即使附带单路参数仍作用于全部通道，避免组合动作继续。
JOG在指令队列非空、侧别切换或预设动作进行中返回interface unavailable；
等待已有指令应用后可重试。JOG时间省略时为1000 ms，MOVE时间可为0。
旧ANGLE命令保留换算兼容，仍经过相同限位检查；SWEEP全部禁用。
所有目标先校验再入队，越界不会截断到边界，也不会部分执行。

## 右臂预设动作

| 指令 | A | B | C |
| --- | --- | --- | --- |
| SERVO RESET [ms] | 1500 | 1500 | 1500 |
| SERVO EXTEND [ms] | 875 | 1500 | 保持 |
| SERVO RETRACT [ms] | 1500 | 1500 | 保持 |
| SERVO OPEN [ms] | 保持 | 保持 | 1500 |
| SERVO CLAMP [ms] | 保持 | 保持 | 1000 |
| SERVO GRIP [ms] | 保持 | 保持 | 850 |
| SERVO PICK [ms] | 分步动作 | 分步动作 | 分步动作 |

默认1000 ms，范围1–600000 ms；PICK时间为每一步时长，不是总时长。
CLAMP只是暂定夹持位置，不是力控制，具体力度随物体尺寸变化。
PICK按松爪→伸出→合紧→停顿200 ms→收臂执行，最后C保持850。
若某步已经到位，会直接进入下一步。底盘和转台不联动。
新显式动作会取消余下自动步骤；HOLD/OFF会同时清除待执行舵机命令。
切换SIDE停止旧侧运动，不恢复旧侧自动流程。预设仅真实R可用。

插值使用smoothstep曲线，起止速度为零，协同关节共用时长，但不保证末端直线。
ok servo queued只表示指令接收，动作状态是输出进度，不是实际位置反馈。
参数存在工程配置，未提供Flash运行期保存；复位恢复配置。
